## 2026-03-29 - [CRITICAL] Fix Uncontrolled Resource Consumption (CWE-400) in command execution
**Vulnerability:** The `executeCommand` utility spawned child processes using `child_process.spawn` and blindly concatenated their `stdout` and `stderr` streams into unbounded strings. A malicious process or an infinite loop generating massive output could exhaust Node.js heap memory, resulting in a Denial of Service (DoS) via process crash.
**Learning:** Even safe command execution strategies (like using array arguments to prevent shell injection) must guard against resource exhaustion at the output stream level. We cannot assume child processes will be well-behaved and produce finite output before they exit or time out.
**Prevention:** Implement a hard limit (`maxBuffer`, default 1MB) on output streams accumulated from child processes. If exceeded, immediately kill the rogue process using `SIGKILL` and cleanly reject to prevent memory starvation of the primary node process.
